# 👑 Royal Tambola Online

A multi-device, real-time online Tambola (Housie) web application with voice announcements, animated draw popups, and host-validated prize claims.

## Features
- **Online Multi-Device Sync:** Shareable invite URLs (`?room=TAM-XXXX`) with multi-STUN/TURN WebRTC connectivity.
- **All Standard Rules:** Jaldi Five, Top Line, Middle Line, Bottom Line, Four Corners, and Full House.
- **Anti-Bogey Verification:** Every claim is verified against the master called-number list.
- **Session Recovery:** Refreshing the browser preserves your 3×9 ticket and marked numbers.

## Deploy on GitHub Pages
1. Create a new repository on GitHub (e.g., `royal-tambola-online`).
2. Upload `index.html`, `style.css`, `app.js`, and `README.md` to the `main` branch.
3. Go to **Settings → Pages → Build and deployment**.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`, and click **Save**.
5. Open your live `https://<username>.github.io/royal-tambola-online/` link and share room links with friends!
